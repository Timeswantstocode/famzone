## 🚀 Features

</div>

<details>
<summary><b>🤖 FAM AI & Story Hub</b> - <i>Reconstruct your memories</i></summary>
<br />

| Feature                          | Description                                                                                  |
| :------------------------------- | :------------------------------------------------------------------------------------------- |
| 📚 **Story Hub (The Librarian)** | Get contextual recaps of past seasons or prequel movies before starting a new one.           |
| 🧠 **Watchlist AI Summaries**    | Persistent background analysis of your watchlist offering smart status reports and insights. |
| 🔍 **Discovery AI**              | Recommends modern and relevant shows using recency signals and your "Recently Watched" era.  |
| 🔔 **Airing Alerts**             | Automatic highlights for shows from your watchlist airing new episodes today.                |

</details>

<details>
<summary><b>⚽ Football Hub</b> - <i>Never miss a match</i></summary>
<br />

| Feature                       | Description                                                              |
| :---------------------------- | :----------------------------------------------------------------------- |
| 🔴 **Live Match Tracking**    | Real-time scores with auto-refresh for ongoing matches                   |
| 📡 **Multi-Source Streaming** | Priority-ranked source tiers with automatic fallback                     |
| 📊 **Match Statistics**       | Possession, shots, corners, fouls - all live                             |
| 👥 **Team Lineups**           | Full formation visualization with player details                         |
| 🌍 **30 Competitions**        | Premier League, La Liga, Bundesliga, Serie A, Champions League, and more |
| ⏱️ **Match Countdown**        | Countdown timers for upcoming fixtures                                   |

</details>

<details>
<summary><b>🎬 Movies & TV Shows</b> - <i>Your massive cinematic library</i></summary>
<br />

| Feature                   | Description                                                            |
| :------------------------ | :--------------------------------------------------------------------- |
| 🎞️ **Extensive Library**  | Browse thousands of titles via TMDB integration                        |
| ▶️ **Provider Players**   | Ten curated embed sources; quality and subtitles come from the provider |
| ⏪ **Resume Playback**    | Nxsha position history on the Hope source; other sources start fresh   |
| 📋 **Watchlist**          | Personal list with statuses: Watching, Completed, On Hold, Dropped, Plan to Watch, Rewatching |
| 🔥 **Trending & Popular** | Curated rows of what's hot right now                                   |
| 🎠 **Hero Carousels**     | Cinematic featured content banners                                     |

</details>

<details>

| 🔗 **AniList Integration**   | Sync your anime list, track progress, OAuth login |
| 📅 **Airing Schedule**       | Weekly calendar of upcoming episodes              |
| 🏷️ **Advanced Filters**      | Search by genre, tags, popularity, and score      |
| 🎵 **Multi-Source Playback** | Multiple streaming providers with quality options |
| ✅ **Episode Tracking**      | Automatic watched episode progress                |
| 🗺️ **Browse & Discover**     | Curated galleries and trending anime              |

## 🔐 Security

</div>

FAM Zone is built with a focus on security and performance, featuring:

> 🛡️ **HSTS** - Strict Transport Security for encrypted connections
>
> 🛡️ **X-Frame-Options** - Industry-standard Clickjacking protection
>
> 🛡️ **X-Content-Type-Options** - Robust MIME-type sniffing prevention
>
> 🛡️ **Referrer-Policy** - Privacy-focused origin handling
>
> 🛡️ **Permissions-Policy** - Fine-grained hardware access control
